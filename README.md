# ELYVEX

A mobile phone discovery and comparison web app. Visitors can explore phones by category or requirements, receive ranked recommendations, and compare two selected phones. Firebase Authentication is optional; signed-in users can save recommendation preferences for future visits. The current catalog is `Datasets/sic_mobile_spec_PJ1.xlsx`; see [dataset notes](docs/dataset-notes.md) before connecting it to the app because the currency and several units need confirmation.
