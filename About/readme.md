# Product brief: ELYVEX

## Purpose
Help people find a mobile phone that fits their needs and compare two shortlisted phones using consistent specifications and clear trade-offs.

## Core experiences
- Browse by category (for example, budget, camera, gaming, battery, or flagship) and by user-entered requirements such as budget and preferred features.
- Receive ranked recommendations with a short explanation of how each phone matches the selected requirements.
- Select exactly two phones for a side-by-side specification comparison.
- Sign up, sign in, and sign out through Firebase Authentication.

## Initial scope
The product catalog comes from a CSV supplied by the project owner. This scaffold does not assume a particular vendor, currency, or finalized CSV column naming. Dataset mappings and validation belong in the backend data layer. Authentication is for identity; Firebase configuration must be provided through local environment variables.

## Not in the initial scaffold
Live retailer prices, stock checks, product ingestion, saved user lists, and an admin catalog editor.
